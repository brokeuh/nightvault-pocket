Connect your GitHub account (once per device)

The page needs a GitHub key that may start jobs in nightvault-pocket. The key stays on this device only (it is never put in the app or on the site).

  1. Open github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Name: Nightvault control. Expiration: as long as you like (for example 1 year).
  3. Repository access: Only select repositories → brokeuh/nightvault-pocket.
  4. Permissions → Repository permissions → Actions: Read and write. Nothing else is needed.
